# OpenPulse Scripts

Use this folder as your local script workspace.

- `examples/` contains starter scripts that OpenPulse can load from the Script Library.
- `custom/` is the recommended place for your own scripts.
- `data/` contains local sample data used by the starter scripts.

Scripts can print plain text or JSON. In OpenPulse, use the Script monitor flow to preview output, select a scalar value or item list, choose a condition, and save the monitor.
